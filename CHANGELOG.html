1.0.0 - 2026-04-17

Added

  • FileQueryRuntime.Create() — composition root for creating a default engine instance.
  • IFileQueryEngine — core engine interface with synchronous Execute and asynchronous ExecuteAsync methods.
  • FileQueryBuilder — fluent API for constructing file queries (From, Where, UsingGitIgnore, UsingGlob, UsingRegex, UsingHybrid, IgnoreCase, WithRecursion).
  • FileQueryOptions — immutable query configuration covering recursion depth, case sensitivity, symlink policy, and traversal strategy.
  • PatternInput — public pattern configuration type supporting raw patterns, explicitly typed patterns, and interpretation mode.
  • GitIgnore matcher — directory-aware pattern evaluation with negation, root anchoring, directory-only rules, and recursive wildcards.
  • Glob matcher — classic wildcard matching (*, **, ?, [a-z], [!abc]) applied to full normalized paths.
  • Regex matcher — full .NET regular expression matching via the r: prefix.
  • Hybrid matcher — unified pipeline that supports all three pattern dialects in a single query.
  • Pattern classification, canonicalization, tokenization, and invariant enforcement pipeline.
  • TraversalFrontier — ArrayPool<T>-backed frontier supporting both depth-first and breadth-first traversal strategies.
  • Zero-allocation hot path — all matcher evaluation produces no heap allocations.
  • Jeninnet.FileQuery.CommandLine — System.CommandLine integration mapping --patterns, --gitignore, --glob, and --regex arguments into engine pattern input.
  • Jeninnet.FileQuery.DependencyInjection — AddFileQuery() extension method for Microsoft.Extensions.DependencyInjection.
  • Six sample projects covering basic matching, pattern language, recursive traversal, hybrid matching, regex matching, and advanced DI + CLI usage.
  • BenchmarkDotNet benchmark suite covering all matchers, pattern tokenization, classification, and traversal.
  • Architecture tests enforcing layer boundaries, zero-allocation contract, and matcher construction authority.
  • Full XML documentation on all public members.
  • Symbol packages (.snupkg) for debugger step-through support.

Notes

  • Targets net10.0. Requires .NET 10 or later.
  • All three packages versioned together at 1.0.0.
  • The PatternMatchingMode property on FileQueryOptions applies only when PatternInterpretationMode.Specific is set. In the default Hybrid mode it is ignored.
  • GitIgnore sub-set results take precedence over Glob and Regex sub-sets in hybrid mode. A GitIgnore inclusion is final; Glob and Regex matchers can re-include paths excluded by GitIgnore but cannot exclude paths that GitIgnore has included.
